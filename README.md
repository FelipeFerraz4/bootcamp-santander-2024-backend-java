# Bootcamp Santander 2024 - Backend Java

Repositório destinado à consolidação das atividades, desafios, laboratórios e projetos desenvolvidos durante o **Bootcamp Santander 2024 - Backend Java**.

Os projetos originalmente desenvolvidos em repositórios separados foram reunidos neste repositório, mantendo seus respectivos **históricos de commits**.

## 📂 Projetos

| Projeto                                                    | Descrição                                             |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| [`digital-bank`](./digital-bank)                           | Projeto de desenvolvimento de um banco digital        |
| [`dio-challenge-code`](./dio-challenge-code)               | Desafios de programação                               |
| [`dio-collections-task`](./dio-collections-task)           | Atividades relacionadas a Collections em Java         |
| [`dio-lab-api-client`](./dio-lab-api-client)               | Laboratório de desenvolvimento de cliente para API    |
| [`dio-lab-bootcamp`](./dio-lab-bootcamp)                   | Atividades e exercícios gerais do bootcamp            |
| [`dio-lab-controle-de-fluxo`](./dio-lab-controle-de-fluxo) | Laboratório sobre controle de fluxo em Java           |
| [`dio-lab-project-iphone`](./dio-lab-project-iphone)       | Projeto de modelagem das funcionalidades de um iPhone |
| [`dio-stream-api-task`](./dio-stream-api-task)             | Atividades utilizando Stream API do Java              |

## 📚 Conteúdos praticados

Durante os projetos foram abordados conceitos como:

* Fundamentos da linguagem Java
* Programação Orientada a Objetos
* Classes, interfaces e herança
* Collections
* Generics
* Tratamento de exceções
* Controle de fluxo
* Stream API
* Desenvolvimento de APIs
* Consumo de APIs
* Arquitetura e organização de projetos
* Versionamento com Git

## 🕐 Histórico

Os projetos foram originalmente mantidos em repositórios independentes. Posteriormente, foram consolidados neste repositório utilizando **Git Subtree**, preservando o histórico de commits de cada projeto.

Dessa forma, além de centralizar os projetos, este repositório mantém o histórico de desenvolvimento realizado durante o bootcamp.

## 🎓 Contexto

Projetos desenvolvidos como parte da formação **Santander 2024 - Backend Java**, em parceria com a [Digital Innovation One (DIO)](https://www.dio.me/).
